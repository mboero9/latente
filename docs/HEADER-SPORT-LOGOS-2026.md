# Identificación visual de deportes en el header (2026-10-17)

Se reemplazan los emoji del menú de navegación por logos **solo cuando hay
una identidad institucional asociada verificable**. Esto incluye NBA, F1,
NFL, NHL, MLB y WNBA; y logos de las federaciones ICC, FIBA, IHF y FIVB en
las pestañas de las categorías globales correspondientes.

Fuentes Wikimedia Commons (nombre exacto de archivo usado, URL
`https://commons.wikimedia.org/wiki/Special:FilePath/<nombre_codificado>`):
- NBA: `National Basketball Association logo 2017-present.svg`
- Fórmula 1: `Formula One logo.svg` (identidad vigente)
- NFL: `NFL wordmark logo 2008.svg`
- NHL: `National Hockey League shield.svg`
- MLB: `Major League Baseball logo.svg`
- WNBA: `WNBA logo.png`
- Cricket (ICC): `ICC logo (2026).svg`
- Básquet (FIBA): `FIBA logo.svg`
- Handball (IHF): `Internationalen Handballföderation.png`
- Vóley (FIVB): `Fédération Internationale de Volleyball logo.svg`

Rugby representa varias ligas y uniones sin marca única: conserva su
pictograma genérico para no poner el logo de una competencia por otra. El
pictograma también aparece si una imagen no puede cargarse. Los logos son
identificaciones editoriales, **no patrocinio ni licencia comercial**; hay
derechos marcarios aunque el archivo vectorial esté etiquetado como dominio
público o texto simple.

El menú conserva el orden FIFA/fútbol local, guías, NBA y F1 juntos, el
control de deslizamiento y las rutas. Los logos no alteran ni alimentan datos.
F1 sigue teniendo vista móvil independiente (tarjetas) para evitar nombres
partidos letra por letra.

Antes de aumentar el uso de logotipos en inventario publicitario o materiales
comerciales, verificar permisos pertinentes y la aprobación de AdSense.
